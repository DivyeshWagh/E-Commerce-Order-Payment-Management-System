# E-Commerce Order & Payment Management System

A full-stack e-commerce application built using Java, Spring Boot, React.js, and PostgreSQL.

## Tech Stack

- Java
- Spring Boot
- Spring Security
- JWT
- Hibernate
- Spring Data JPA
- React.js
- PostgreSQL
- REST API
- Maven
- Postman

## Features

- User Registration & Login
- JWT Authentication
- Role-Based Authorization
- Product Management
- Category Management
- Shopping Cart
- Checkout
- Order Management
- Inventory Management
- Payment Management
- Admin Dashboard
